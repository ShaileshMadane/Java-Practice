🏦 Banking Program

A simple console-based Banking Program built in Java that allows users to manage a basic bank balance through a menu-driven interface.

This project was created to practice fundamental Java concepts such as loops, switch statements, methods, user input, conditional statements, and variables.

📌 Features

The program provides the following options:

Show Current Balance
Displays the user's current account balance.
Add Amount
Allows the user to deposit money into the account.
Negative amounts are rejected.
Withdraw
Allows the user to withdraw money.
Prevents withdrawal when there is insufficient balance.
Negative withdrawal amounts are rejected.
Exit
Safely exits the banking program.
🛠️ Technologies Used
Java
Scanner for user input
while loop for continuous menu operation
switch statement for menu selection
Methods for separating banking operations
